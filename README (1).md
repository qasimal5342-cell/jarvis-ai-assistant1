# JARVIS AI Assistant

A free, mobile-friendly browser voice assistant with a futuristic JARVIS-style interface.

## Features
- Voice input with the Web Speech API
- Spoken replies with browser speech synthesis
- Futuristic responsive interface
- Time and date
- Google search
- Open YouTube, Google, GitHub, Facebook, WhatsApp Web, Instagram, Gmail and Bilibili
- Calculator commands
- Local notes using browser storage
- Command history
- PWA manifest

## Example commands
- "What time is it?"
- "Open YouTube"
- "Search Google for latest AI news"
- "Calculate 25 times 4"
- "Save note buy a microphone"
- "Show notes"
- "Clear notes"
- "Help"

## Run
Open `index.html` in a modern browser. Chrome is recommended for voice recognition.

## GitHub Pages
1. Upload all files to your repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

## Important
This is a browser-based assistant. Browser security does not allow a static web page to execute arbitrary computer shell commands. This version also does not expose a paid AI API key.

The project is ready for future upgrades such as a real AI backend, Urdu voice commands, wake-word support, weather, news, reminders, and other integrations.
